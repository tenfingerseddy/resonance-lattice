Resonance Lattice on Microsoft Fabric

A team-shared knowledge model that lives inside your Microsoft Fabric tenant. One .rlat file in OneLake, exposed as a grounded data source for your Fabric data agent and as a search endpoint for Claude Code, Cursor, and other LLM assistants — with no Azure OpenAI, no third-party vector database, and no data leaving your tenant.
